# manga-art — コードで「素人っぽくない」漫画を描く

図形を組み合わせただけの絵は、線の太さが均一で、髪がギザギザで、陰影がないため素人っぽく見える。
このスキルは、プロの作画の基本をコードで再現できる形にまとめたもの。

- ライブラリ: `scripts/mangakit.py`(描画部品と網点化)、`scripts/render.js`(SVG→PNG)
- 見本: `examples/girl.py`(デフォルメ女の子、表情4種)。新キャラはこれを複製して改造する
- 調査メモと出典: `references/research.md`

## 前提
- Chromium と Playwright(`require('playwright')`)、Python の numpy と Pillow
- 日本語フォント: `apt-get install -y fonts-noto-cjk fonts-noto-cjk-extra`
  (明朝かな+ゴシック漢字のアンチック体を CSS で合成するため、Noto Serif/Sans CJK JP の Bold と Black を使う)

## 最小の使い方
```python
import sys; sys.path.insert(0, '<skill>/scripts'); sys.path.insert(0, '<skill>/examples')
from mangakit import Page
from girl import girl
p = Page(820, 560)                                   # 1コマ分
p.tone('M 0 0 L 820 0 L 820 560 L 0 560 Z', '#efefef')  # 背景の薄いトーン
girl(p, 560, 250, 1.3, rot=-4, eyes='sparkle', mouth='smile')
p.bubble(160, 230, 118, 175, '今日こそ<br/>仲良くなる！', tail=(395, 250), size=32)
p.sfx(700, 330, 'ぐっ', 52, rot=12)
p.save('panel.png')   # tone/ink の SVG と PNG を書き出して網点合成
```

## 二層モデル(必ず守る)
| 層 | 何を描く | 色の意味 |
|---|---|---|
| tone | 灰色の面 | 灰色の濃さ → 網点の大きさ。白はトーン無し |
| ink | 線と、下を隠す白 | 黒=墨、白=下の線を隠す |

- `p.fill(d, gray)` は tone 層に灰色、ink 層に白を同時に置く。キャラの前後関係はこの白で作る。
- トーンの上に白い線(髪のハイライト、襟のライン)を引くときは `p.tone(taper(...), '#fff')` を使う。ink 層の白はトーンを消せない(合成は min)。
- 網点の細かさは `save(lpi=9)`。2倍出力で 9 前後が上品。12 以上は粗く素人っぽくなる。

## 素人っぽさを消す8つのルール

### 1. 線は全部「入り抜き」付きで描く(SVG の stroke は使わない)
- `p.line(d, w, tin, tout)` は、中心線から幅が変わる多角形を作って塗る。`tin`/`tout` は入りと抜きの長さで、全長に対する割合。
- 目安: 髪の毛筋 `tin .35 tout .45`、上まつげ `w 7.5 tin .12 tout .08`、目尻のハネ `tin 0 tout .85`。
- 継ぎ目を作らない。1本の線は1本のパスで描く。吹き出しのしっぽも本体と一体の輪郭にする(`p.bubble` が自動でそうする)。

### 2. 線の強弱は「階層」と「光源」で決める
- 階層の目安: 輪郭 3.0〜3.4 > 服のパーツ 2.4 > 顔の内側(鼻・口・二重)1.4〜2.2 > 頬の斜線・シワ 1.4。
- `p.shape(d, gray, w, light_k)` の輪郭は、光源(既定は左上 `LIGHT`)の反対側ほど自動で太くなる。顔は `light_k=0.9`、エフェクト類は 0〜0.3。
- 光源は1コマの中で1つに統一する。目のハイライトも、左右の目とも光源側に置く(左右対称にミラーしない)。

### 3. 髪は「面」ではなく「毛束」で描く
- 頭頂の面(cap)を描き、つむじ(分け目)の点から放射状に毛束 `clump(..., profile='leaf')` を重ねる。
- 外側の束から先に描き、内側の束を手前に重ねる。束の幅や長さ、曲がり(bend)は1本ずつ変える。
- 横髪や後ろ髪は `profile='hang'`(根元が太く、毛先が細い)。
- 毛束の影側の半分に影トーンを貼る(`examples/girl.py` の `_hair_clump`)。
- 天使の輪は、毛の流れの向きに沿った短い白の入り抜きを弧に沿って並べ、ギザギザに切る。一本の帯にしない。
- 前髪は眉の高さ〜目の上で止める。目にかけない。

### 4. 影は2段トーンで、縁を残す
- ベーストーン(固有色): 髪 `#c4c4c4`、制服の襟 `#a8a8a8`
- 影トーン: 髪 `#8e8e8e`、肌 `#e2e2e2`(1段目)と `#c8c8c8`(2段目、顎下・首)
- 影は光源の反対側に置く(頬の右側、顎の下、襟の右半分)。`tone_clip_open(face)` で輪郭の内側に切り抜く。
- 濃いトーン(#6x 以下)を広く使わない。画面が汚れて見える最大の原因になる。

### 5. 顔のバランス(デフォルメ・可愛い系)
- 目は顔の高さの中心より下(顔の上端 -95、下端 +103 に対して目の中心 +36)。パーツを下・中央に寄せると幼く可愛くなる。
- 両目の間は、目の幅のおよそ0.6〜1つ分。近づけすぎない。
- 目は作りを重ねる: 白目の形 → 虹彩(上が濃いグラデーション)→ 瞳孔 → 下側の反射(白)→ ハイライト2つ → 上まつげ(太い主線)→ 目尻のハネ → 二重 → 下まつげ。
- 頭を ±2〜6° 傾ける(`rot`)。完全な正面と左右対称は、動きのない硬い絵になる。
- 口は小さく、顔の下から1/4あたり。開いた口の中を濃いトーンで塗ると、歯や牙に見えやすい。薄め(#b0b0b0)にするか、線だけにする。

### 6. 写植はアンチック体、縦書き
- `ANTIQUE`(明朝かな+ゴシック漢字)を吹き出しで使う。描き文字は `MSfx`(Noto Sans CJK Black)に白フチを付ける。
- 吹き出しのセリフは縦書きで、1行6〜7文字まで。改行は `<br/>`。
- 「〜」は縦書きで向きが崩れやすい。音符や「ー」で代用する。

### 7. 漫画記号はキャラの外側に置く
- 汗、縦線、頬の斜線、キラキラ(`p.sparkle`)、集中線(`p.focus_lines`)。
- 汗は頭の外、縦線は額の上、キラキラは背景に置く。顔の中に詰め込まない。

### 8. 自分で見て直す(必須)
描いたら必ず PNG を Read で開いて、次のチェックリストで確認する。1回で終えない。

## 仕上がりチェックリスト
- [ ] 太さが均一な線(SVG stroke)が残っていない
- [ ] 前髪が目にかかっていない。毛束の流れがつむじに向かって揃っている
- [ ] 目のハイライトが両目とも同じ側にある
- [ ] トーンが濃すぎない(画面全体が灰色っぽくなっていない)
- [ ] 口が牙や歯に見えない
- [ ] 吹き出しのしっぽが話し手を指している。しっぽと本体の継ぎ目がない
- [ ] パーツ同士の意図しない重なりがない(猫の足がメガネに見える、など)
- [ ] 1コマの中で光源が統一されている

## 4コマの作り方
1. 起承転結を1コマ1行で書く。「結」は絵だけでオチが分かるように。
2. 各コマの役割に合わせて表情を割り当てる。表情は `eyes` = open / sparkle / closed / shock / flat、`mouth` = smile / small / shock / wavy、`fx` = gloom / sweat の組み合わせで作る。
3. ページは幅 900、コマは 820×560、コマの間隔 26、上にタイトル帯 120。
   コマごとに `p.open('transform="translate(40 y)"')` と `p.clip_open(コマ矩形)` で囲む。最後にコマ枠を太さ6の黒で描く。
4. カメラを変える。アップ、引き、2人並び、のように毎コマ同じ構図にしない。

## 既知の限界
- 全身ポーズ、手、パース(遠近)のある背景は、部品がまだ無い。必要なら見本と同じ作法で部品を足す。
- 線は「整った入り抜き」なので、手描きの揺らぎは控えめ(`wobble` で調整)。
